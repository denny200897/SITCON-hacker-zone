## 3. 外部審查（docs/acceptance-m0a-m0c.md）結論與我方驗證

外部「更強 AI」審查判定 M0a–M0c **未通過**，列 3 P0 / 4 P1 / 3 P2。我已逐條讀源碼驗證，**全部屬實**：

- **P0-1** witness 可偽造 trusted oracle artifact：out volume 可寫掛載（`flags.go:155`）、sitecustomize 與 witness 同 process 同 uid 寫 `/aegis/out/sql_trace.jsonl`、checker 直接信任 → 可假造 PROVEN
- **P0-2** evidence 不符 `schemas/evidence.schema.json`（`prove.go:328-343` 寫 `kind:"run_result"` 自訂欄位；schema 要求 kind∈negative|positive|exploit＋repo_tree_hash/run_request_hash/run_result/oracle/created_by/verified_by），且 artifacts 無 hash 綁定
- **P0-3** secrets 可外洩：read_code/search_code 原文直回、Finding.Context 未掃、operator tails 只遮 nonce、audit 在 secret scan 前落盤
- **P1-1** fail-open：`ValidateSpec` nil 即跳過；audit append 錯誤靜默吞
- **P1-2** replay 非自包含（依賴絕對 artifacts_dir＋in-memory `*ProveResult`）
- **P1-3** Runtime.Run 回傳完整 history 但 `msgs=append(msgs, history...)` 每輪重複膨脹；submit 核可後 Runtime 不停、同回應多重 submit 覆蓋
- **P1-4** ASTCheck 是 strings.Contains 字串搜尋（非 §17.9-2 digest-pinned AST helper）
- **P2-1** provider protocol：無 Stream:true、refusal/max_tokens 誤歸 no_spec_submitted、openai-compat 無 429/5xx 退避、schema 重試非上限 2
- **P2-2** reclaim helper hardening 不全、cpTarStdin 無 ctx/timeout、Start 不接收取消
- **P2-3** evidence store 非 append-only（可覆寫、無 O_EXCL、開啟只驗鏈尾）

**P0-1 修法已定案**（記入新 ADR 0004）：同容器 shim=witness 同 process → in-container trace 皆可偽造；分 uid 需 root entrypoint 違反 §7.1 → **唯一合規設計＝獨立 trusted proxy 容器**（Go 靜態 binary＋modernc.org/sqlite 純 Go；SQL 一律經 proxy 實際執行，trace 由 proxy 落自己的 out volume；witness 容器無可寫掛載觸及）。殘餘風險（SQL 內容模仿 runtime 不可觀察）誠實記錄。必要 adversarial test：偽造 sql_trace.jsonl 仍不得 PROVEN。
